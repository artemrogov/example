# Локальный стенд для тестирования механизма SSO

## Установка frontend spa приложения

```bash

#установка зависимостей (пакетов)

npm install

# запуск frontend приложения

node server.js

```

## Открыть в браузере

http://localhost:10000

### Версии зависимостей

- Используется Node.js версии 12
- При необходимости можно обновить версию Node.js
